# 主页面 Typeless 风格改版设计

## 问题

当前主页把四个功能做成同尺寸、同权重的大卡片，说明文字和颜色边框较多，权限状态又占据完整卡片，导致页面更像功能介绍而不是高频工具入口。主动作不明确，极速识别与钉图也没有出现在主页。

## 方向

视觉关键词为安静、快速、精确、原生。移除大面积渐变与多色卡片，只使用系统背景、低对比度分组底色和单一系统强调色。

页面分四层：

1. 顶部品牌区：40 点图标、产品名、简短说明，以及“本地运行”状态胶囊和设置按钮。
2. 主入口：整行“通用截图”，突出快捷键和“开始截图”，整块可点击。
3. 快速操作：极速识别、复制图片、截图翻译、钉在屏幕、滚动长图、钉剪贴板六个紧凑卡片，以 3×2 网格排列。
4. 底部状态：权限与当前运行状态合并为一条轻量状态栏；只有缺少权限时才显示醒目的授权按钮。

## 组件规则

- 窗口默认 840×570，最小 740×550。
- 页面外边距 28，模块间距 22，网格间距 12。
- 主入口圆角 16，快速卡片圆角 13。
- 快速卡片使用单色图标；悬停时只增加轻微强调色背景与边框。
- 快捷键使用等宽圆角字体和低对比度胶囊。
- 所有按钮保留 VoiceOver 标签、键盘焦点和禁用状态。

## 验收

- 第一眼能识别“通用截图”为主动作。
- 六种截图模式都可以从主页直接触发。
- 权限已开启时不再出现大块权限卡。
- 780×580 以上窗口无截断，暗色模式继续使用系统动态颜色。
