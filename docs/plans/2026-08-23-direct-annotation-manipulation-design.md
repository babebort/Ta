# 原位文字与标注对象直接变换设计

日期：2026-08-23

## 目标

- 工具条整体等比例缩小，保留可点击性，但不再遮挡截图内容。
- 文字工具不打开模态对话框，点击截图后直接在原位置输入，回车完成、Esc 取消本次输入。
- 保留“框选马赛克”，同时提供真正连续笔迹的“涂抹马赛克”，粗细由工具条滑杆控制。
- 所有标注对象创建后立即处于可编辑状态。原位工具条移除单独的手形调节按钮：点击对象即可移动，拖动四角控制点即可等比例缩放，双击文字即可原位编辑。

## 交互决策

工具按钮从 36×34 点缩小为 32×30 点，SF Symbol 从 14 点缩小为 12 点，间距和工具条内边距同步缩小。文字使用明确的 `T`，两种马赛克继续使用网格和带颗粒的画笔作为独立入口。

文字输入改为画布内部的 `NSTextField`。输入框位于点击位置，限定在截图边界内，不启动 `NSAlert.runModal()`，因此不会被 screen-saver 级遮罩盖住而造成“卡死”。回车提交为文字标注；Esc 只取消本次输入；失去焦点时提交非空文字。双击已有文字复用同一个输入框进行编辑。

对象交互优先级为：四角缩放控制点、已有对象、当前绘制工具、空白区域。拖动控制点以对角控制点为锚点，通过拖动向量在原始对角线上的投影计算统一缩放比例，避免拉伸变形；拖动对象主体则平移。这样矩形、箭头、文字、马赛克笔迹等全部复用同一套直接操作逻辑。

## 验收标准

- 工具条比当前版本整体缩小约 10–15%，图标仍完整且可辨认。
- 点击 `T` 后输入框直接出现在截图上，不出现模态弹窗，不会假死。
- 涂抹马赛克按鼠标轨迹连续生效；框选马赛克仍可用。
- 矩形、箭头、文字、框选马赛克和涂抹马赛克均可直接点击移动，并可拖四角等比例缩放。
- 撤销/重做、复制、保存、钉图和 Esc 退出不回归。
