# 智谱连接、长截图完整性与钉图移动修复设计

## 目标

1. “保存并测试”只要模型接口真实可调用就成功，不再把连通性误报成翻译失败。
2. Codex 等带固定侧栏、标题栏和输入框的聊天应用，自动长截图不能跳过中段。
3. 钉图允许拖到菜单栏上方或屏幕边缘之外，与左右、下方移动行为一致。

## 方案

- 智谱纯文字测试使用 OpenAI 兼容协议规定的字符串 `messages[].content`；只有视觉请求才使用内容数组。继续显式关闭 Thinking，并保留文字与视觉两段真实测试。
- 自动滚动从不可控的多次“滚轮行”事件改为一次精确像素滚动，维持约一半视口的重叠。拼接匹配忽略常见固定侧栏和底部输入区；渲染时以多帧稳定检测的保守值消除固定顶部/底部，避免单帧误判影响整张长图。
- `PinnedImagePanel` 单独覆盖 macOS 的窗口可见区域约束，拖拽坐标保持原值；设置窗口和其他业务窗口不受影响。

## 验收

- 请求结构测试覆盖智谱纯文字 `content` 类型与视觉内容数组。
- 合成长截图用例包含固定侧栏、固定输入框和连续四帧滚动，并逐段比对中间像素。
- 钉图窗口测试确认顶部超出菜单栏的 frame 不会被系统重写。
- 完整 Swift 测试、签名构建和 `codesign --verify --deep --strict` 通过。
