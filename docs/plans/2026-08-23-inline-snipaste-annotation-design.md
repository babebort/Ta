# 原位标注交互设计

日期：2026-08-23

## 目标

通用截图框选后点击“标注”，截图继续停留在原来的屏幕位置，屏幕其余区域维持半透明遮罩，并在截图下方显示可直接操作的标注工具条，体验接近 Snipaste。

## 交互

1. 用户完成框选，点击现有操作条中的“标注”。
2. 应用隐藏选区层并捕获原选区，随后立即在同一位置展示捕获结果；背景保持变暗。
3. 截图下方优先展示工具条；下方空间不足时自动放到截图上方，水平方向始终限制在当前屏幕内。
4. 工具条直接提供选择、矩形、椭圆、箭头、画笔、高亮、文字、编号、马赛克、模糊和裁剪；同时提供颜色、粗细、撤销、重做、复制、保存、钉图、取消和完成。
5. `⌘Z` / `⇧⌘Z` 撤销与重做，`Escape` 或右键取消，`Enter` 完成并复制标注后的图片。
6. 复制、保存或钉图成功后结束本次截图；单纯取消不修改剪贴板。

## 架构

- 复用现有 `AnnotationCanvasView` 的绘制、裁剪、对象编辑和渲染能力，不重复实现标注算法。
- 新增一个全屏透明 `NSPanel` 作为原位标注宿主：根视图绘制遮罩，选区内嵌无内边距画布，工具条作为同一层级的浮动控件。
- `CaptureCoordinator` 在 `.edit` 路径捕获图片后打开原位标注会话，并一直保持捕获状态，直到用户复制、保存、钉图、完成或取消。
- 原有独立标注编辑器继续保留，供图片翻译后的微调和 UI smoke 测试使用。

## 验收

- 标注图片的位置与原选区一致，截图外区域变暗。
- 工具条不会超出当前显示器，并优先贴在截图下方。
- 马赛克、矩形和文字可以直接添加，撤销/重做有效。
- 完成复制、保存、钉图和取消均能正确关闭遮罩并恢复原 App。
- 现有独立标注器和其他截图动作不回归。
