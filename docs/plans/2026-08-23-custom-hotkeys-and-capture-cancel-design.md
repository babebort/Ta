# 自定义快捷键与截图退出体验设计

日期：2026-08-23

## 目标

1. 六种全局截图动作都允许用户自定义快捷键：极速识别、通用截图、复制图片、截图并钉住、滚动长截图、截图翻译。
2. 框选过程中按鼠标右键与按 Escape 行为完全一致：立即退出截图模式，不生成截图、不修改剪贴板。
3. 使用全局快捷键开始截图时不显示或唤起 AI Screenshot 主界面。

## 交互方案

- 设置新增“快捷键”标签页，每个动作显示名称、用途和当前组合键。
- 点击组合键按钮后进入录制状态，直接按下新组合键即可保存；Escape 取消本次录制。
- 全局快捷键必须包含 Command、Option 或 Control 中至少一个修饰键；Shift 可作为附加修饰键。
- 应用内重复组合会在保存前阻止。若组合被 macOS 或其他 App 占用，Carbon 注册失败后恢复上一组可用配置，并向用户显示失败原因。
- 提供“恢复默认快捷键”，默认仍为 `⇧⌥⌘1` 至 `⇧⌥⌘6`。
- 主界面、菜单栏和翻译设置中的快捷键文案跟随设置实时变化。

## 技术设计

- `GlobalHotKeyAction` 定义六种动作、固定 Carbon ID、默认组合与界面文案。
- `HotKeyShortcut` 保存虚拟键码、Carbon 修饰键和可读键名；使用 UserDefaults 按动作分别持久化，不涉及敏感数据。
- `HotKeyPreferences` 负责读取、保存、恢复默认值、应用内重复检查，并发送配置变化通知。
- `GlobalHotKeyManager` 监听配置变化并重新注册。更新失败时注销部分注册，恢复最后一组成功配置，再重新注册，避免用户因一次错误设置丢失全部快捷键。
- AppModel 只保存动作闭包，快捷键由管理器动态映射。

## 主页与取消逻辑

- `startCapture` 在展示选区层前主动隐藏欢迎页。
- 欢迎页启动延迟任务和 `applicationShouldHandleReopen` 都检查 `isCapturing`；截图中不显示主页。
- 选区层覆盖 `rightMouseDown`，调用和 Escape 相同的 `onFinish(nil, nil)`，由现有协调器完成窗口关闭、前台 App 恢复及任务取消。

## 验收

- 六个默认组合全部注册且互不重复。
- 修改任一组合后立即生效，界面文字同步更新；重启 App 后仍保留。
- 设置成应用内重复组合时不覆盖原配置；系统冲突时回滚。
- 框选前、拖动中、框选完成等待操作栏时，右键均退出截图模式。
- 主界面已关闭或隐藏时，按任意截图快捷键只出现选区层，主页不出现。
- 全量测试、Release 构建和签名校验通过。
