# Snipaste 风格文字与手涂马赛克设计

## 目标

让截图后的文字输入和手涂马赛克遵循 Snipaste 的核心交互习惯：在原图上直接编辑、工具参数即时可调、右键结束当前标注，并且操作过程中没有模态弹窗或固定宽度输入框。

## 已确认的 Snipaste 行为

- 文字标注使用界面默认字体，默认不描边。
- 文字支持字号下拉选择，编辑时可用鼠标滚轮调整字号。
- `Esc` 在文字编辑中结束文字编辑，而不是退出整个截图。
- 右键结束当前标注；没有正在编辑的标注时，仍沿用本应用既有的右键退出截图。
- 涂抹类工具可用滚轮或 `[`、`]` 调节粗细。
- 文字可再次编辑，笔迹和马赛克等对象可整体移动。

## 文字输入

点击截图后，在点击位置创建透明、无边框、多行的原位编辑器。编辑器字号和最终渲染字号一致，内容增长时自动扩展，遇到截图右边界后换行。回车输入换行；右键、Esc、切换工具或点击别处提交非空文字。

工具栏在选择文字工具时把通用线宽滑块切换为字号下拉框。字号采用常用离散档位，同时允许滚轮逐级调整。双击已有文字重新进入同一个原位编辑器。

最终文字使用 macOS 系统字体和用户选择的颜色，不附加白色描边。

## 手涂马赛克

保留“框选马赛克”和“涂抹马赛克”两个入口。涂抹模式使用圆头、圆连接的连续笔刷；采样点之间插值，避免快速拖动时出现断点或折线。

鼠标位于截图内时显示与实际笔刷直径一致的圆形预览。滚轮或 `[`、`]` 调整笔刷直径，并同步工具栏滑块。像素块强度仍由当前离线马赛克滤镜负责，笔刷只控制涂抹范围。

## 兼容既有交互

- 文字编辑中右键或 Esc：提交文字并结束编辑。
- 正在拖动绘制时右键：结束或取消当前未完成手势，不退出整个截图。
- 没有活动编辑/手势时右键：退出截图模式，满足此前的全局取消要求。
- 已提交的文字和马赛克继续支持直接拖动和四角缩放。

## 验收标准

1. 文字点击后直接出现在原图位置，没有白底输入框。
2. 文字支持多行、字号下拉和滚轮调节；右键与 Esc 都只结束文字编辑。
3. 最终文字无白色描边，输入预览和导出效果一致。
4. 手涂马赛克快速拖动不留断点，首尾为圆头。
5. 鼠标悬停时可看到笔刷直径，滚轮和 `[`、`]` 可调节并与工具栏同步。
6. 空闲状态右键仍然退出截图。
