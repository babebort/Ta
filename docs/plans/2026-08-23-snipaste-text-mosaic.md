# Snipaste 风格文字与手涂马赛克实现计划

## Task 1：可测试的字号与笔迹几何

- 在标注模块增加文字字号档位、字号钳制和笔迹插值工具。
- 为多行文字测量和马赛克插值补充单元测试。

## Task 2：原位多行文字编辑器

- 用透明 `NSTextView` 替换固定宽度的 `NSTextField`。
- 内容变化时自动调整编辑区域，限制在截图范围内。
- 回车保留为换行；右键、Esc、失焦、点击别处提交。
- 双击已有文字时恢复原文字、颜色和字号。
- 移除最终文字的白色描边并修正多行文字边界计算。

## Task 3：工具栏参数切换

- 文字工具显示字号下拉框，其他绘制工具显示粗细滑块。
- 滚轮或键盘调整后，将数值回写到工具栏。
- 独立维护文字字号，避免线宽改变文字大小。

## Task 4：Snipaste 风格手涂马赛克

- 拖动采样点之间进行等距插值。
- 使用圆头圆连接裁剪马赛克图层。
- 增加圆形笔刷悬停预览。
- 支持滚轮和 `[`、`]` 调节笔刷粗细。

## Task 5：验证与发布

- 运行标注相关测试与完整 `swift test`。
- 构建并签名 `artifacts/AI Screenshot.app`。
- 检查发布包签名以及文字、右键和马赛克核心路径。
