# 截图交互与窗口吸附优化设计

## 目标

让截图行为回到一个简单原则：无论当前前台是浏览器、其他 App、菜单，还是「拓」自身，按下快捷键后都应立即进入可操作的截图状态；左键拖拽或点击自动选区完成框选，右键和 Esc 随时取消。通用截图进入标注时，截图画面保持原位且不闪烁。

## 方案选择

覆盖层使用 macOS 原生的非激活 `NSPanel`。快捷键触发后同步创建全屏透明面板，并明确接收第一次鼠标事件；不调用 `NSApplication.activate`，不切换 Space，不生成冻结底图，也不在结束后重新激活所谓“原应用”。截图前、截图中和截图后，用户所在的应用始终不变。

窗口吸附使用 `CGWindowListCopyWindowInfo` 获取快捷键触发瞬间的窗口快照，并把候选严格限定为当时真正位于前台的 App，避免切换到其他 App 后仍命中旧浏览器窗口。鼠标未拖拽时，选择光标下层级最靠前的有效窗口作为候选；层级相同时优先更小的弹窗。单击确认候选，拖拽超过阈值后立即切换为自由框选。截图模式接管全部左键事件，点击和拖动都不会传给底层 App。

## 截图与标注数据流

截图开始时不隐藏 Welcome、设置或其他「拓」窗口。选择面板只绘制半透明遮罩和选区边框，选区内部直接透出当前桌面。确认后关闭选择面板，再通过 ScreenCaptureKit 捕获当前选区；进入标注时则保留选择面板，并在采集时按窗口 ID 排除该面板。整个流程不复制一张假的桌面画面，也不执行应用恢复或切换。

普通动作确认后立即关闭覆盖层再处理。标注动作采用无闪屏交接：覆盖层保留当前选区，截图服务在排除覆盖层后捕获底层内容，先创建原位标注面板，再关闭选择覆盖层。两个面板之间没有裸露桌面的空帧。

通用截图操作栏改为 Snipaste 式紧凑图标栏，左到右为：美化、AI 识图、取字、翻译、标注、钉图、复制、保存，对应用户要求的右到左顺序。按钮统一为方形图标、悬停说明，并按 AI/编辑/输出分组，减少文字造成的拥挤。

## 钉图与快捷键

截图来源的钉图初始尺寸使用选区的逻辑点尺寸，而不是 Retina 像素尺寸；仅当选区超过当前可见屏幕时才等比缩小。粘贴板、文字和文件生成的钉图继续使用安全的默认上限。滚轮缩放以图片中心为锚点，双击关闭及右键菜单保持不变。

快捷键录制与偏好设置允许 `modifiers == 0`。重复组合仍拒绝，Carbon 注册失败仍回滚到上一次可用配置并显示冲突原因。单键快捷键会拦截该按键在其他应用中的输入，这是用户主动配置后的预期行为。

## 验收

- 浏览器前台按快捷键，第一次左键拖拽即可形成选区，前台应用不切换。
- 「拓」窗口保持可见时能够被截图；选择覆盖层不会出现在结果里。
- 右键在空白、选区和工具栏区域都能取消。
- 点击标注后选区画面不出现中间闪帧。
- 悬停窗口/弹窗自动出现候选框；拖拽可覆盖候选框。
- Retina 屏幕上钉图尺寸与原选区视觉尺寸一致。
- 单键快捷键能保存、注册；重复或被系统占用时明确回滚。
