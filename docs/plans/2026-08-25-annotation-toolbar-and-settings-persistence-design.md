# 标注工具栏与升级配置保留设计

## 背景

独立标注窗口当前启用了全尺寸透明标题栏，并把工具、样式、对象变换、历史操作和输出动作塞进同一条横向工具栏。窗口交通灯、标题和编辑控件共享首屏顶部空间，既拥挤，也缺少清晰的操作层级。

模型配置已经分别保存在 `UserDefaults` 和 macOS Keychain，但 Bundle ID、Keychain service 与 account 目前散落在多个文件中。正常覆盖升级不会删除这些数据，不过后续若误改任一持久化标识，旧配置就会无法读取。

## 方案比较

1. 只缩小现有控件：改动最小，但仍然是一条没有层级的长工具栏，窄窗口继续拥挤。
2. 双层分组工具栏（采用）：恢复原生标题栏，第一层放工具、撤销和输出，第二层放样式与对象变换。信息密度明显下降，仍能一眼看到所有高频操作。
3. 完全上下文工具栏：只显示当前工具相关参数，最简洁，但需要新增大量工具状态联动，容易在本轮引入行为回归。

## 工具栏设计

- 窗口使用标准 macOS 标题栏，交通灯和“标注截图”不再与编辑控件重叠。
- 工具区固定为 96 pt 高的两层布局，左右边距 16 pt，行间距 6 pt。
- 第一层左侧为当前工具选择；右侧依次为撤销/重做、复制/保存和强调色“完成”。
- 第二层左侧为颜色、线宽、字号、透明度和虚线；右侧为旋转、缩小和放大所选对象。
- 相关控件放入浅色圆角分组容器，组间 8 pt；图标按钮保持 30 × 30 pt，所有图标保留 Tooltip 和辅助功能名称。
- 最小窗口宽度继续支持 860 pt；两行分别使用弹性空白吸收额外宽度，避免把控件强行拉散。

## 升级配置保留设计

- API Key 继续保存在 macOS Keychain，不写入偏好、日志或安装包。
- 模型地址、模型名、翻译语言、默认模式等继续使用 `UserDefaults.standard`，由固定 Bundle ID `com.kangarooking.AIScreenshot` 关联。
- 新增单一的持久化标识定义，统一 Keychain service 与三类 account；原有字符串值保持不变，因此已有用户无需迁移。
- 回归测试读取真实 `Resources/Info.plist`，确保 Bundle ID 不被误改；同时锁定 Keychain service/account 的历史值，并验证同一标识的新 Store 实例能读取旧 Store 写入的 Key。
- 设置页明确说明：在同一台 Mac 上正常覆盖升级会保留 Key 和模型配置。主动点击“移除 Key”、使用清理软件删除偏好，或更换电脑不属于覆盖升级。

## 验收标准

1. 独立标注窗口标题栏与工具控件不再共享一行。
2. 96 pt 工具区中两行分组清晰，860 pt 窗口宽度下不溢出。
3. 原有工具、样式、撤销/重做、复制、保存和完成行为不变。
4. 现有 Keychain 标识和 Bundle ID 保持不变，持久化契约测试通过。
5. `swift test`、生产构建和真实 UI smoke 截图验收通过。
